# Character prompts: the RAI crew   Source: Tang (chat, 2026-11-25)   Sheets: Tang's 5-character board (chat, 2026-11-24)

The text Tang used to make the character sheets in an image tool. Kept here word for word so anyone can make new sheets, stickers or slides that match. The app draws the same characters in code (`web/src/components/LoginCrew.tsx`); how they behave on the Login page is in `login-crew.md`.

**What the app version changes (on purpose)**
| Prompt says | App draws | Why |
|---|---|---|
| Guy: "premium MacBook Pro laptop" | plain silver slim laptop, no logo | Apple logo is a trademark |
| Hymm: "Ferrari-inspired red", car key fob | plain red key with a gold bolt, gold "H" varsity patch | prompt itself says no real car logos |
| Sheets: front / side / back views, close-ups, swatches | front view only, 4 expressions each | the app only shows the crew from the front |

## CHARACTER DESIGN PROMPT — TANG
Create an original collectible designer-toy character named TANG.

**Character Identity**
- Name: TANG
- Species: Black Panther
- Role: The Alpha / The Leader
- Personality: Energetic, Competitive, Natural Leader
- Core energy: Confident, ambitious, fearless, charismatic.

**Physical Appearance**
- Anthropomorphic black panther.
- Oversized head and compact muscular body.
- Sharp panther ears and expressive golden-yellow eyes.
- Sleek black fur with subtle purple highlights.
- Strong athletic posture.
- Long panther tail.
- Confident facial expression with a slight smirk.

**Outfit**
- Premium black futuristic streetwear jacket.
- Purple and cyan accent details.
- Techwear pants.
- Futuristic sneakers.
- Stylish utility accessories.

**Signature Accessory**
Futuristic oversized headphones with glowing purple and cyan elements. The headphones must be a recognizable part of his identity.

**Color Palette**
- Midnight Black
- Electric Purple
- Neon Cyan
- Small Golden Yellow accents.

**Character Sheet Requirements**
Create a professional character design sheet containing:
1. Main full-body hero pose.
2. Front view.
3. Side view.
4. Back view.
5. Four facial expressions: Confident, excited, competitive, angry.
6. Signature headphones close-up.
7. Outfit and material details.
8. Color palette swatches.

**Art Direction**
Colorful collectible designer-toy aesthetic, exaggerated chibi proportions, thick clean outlines, polished cartoon illustration, glossy toy-like surfaces, vibrant purple background.

**Important**
Make TANG look like a natural leader, not an aggressive villain. His silhouette must be recognizable even without color.
Do not copy existing copyrighted mascot characters. Create an entirely original character.
